# ProjectileType 射弹组件

“游戏数据 → 射弹 ID 修改”已完整替换为 **射弹类型（ProjectileType）** 组件视图。对应游戏中的 `ProjectileSettings → ProjectileInfo`，当前记录长度为 **272 字节**。

参考为用户提供的 `generated_projectile_settings.json`（标注游戏版本 1.007.200、2026-10-20）。其 355 条记录中的 **25,915 项标量值**与当前原始数据逐项匹配，全部一致。类型、偏移、位宽及标志位位置另由当前 `dl_library.dl_typelib` 验证。

## 完整字段

每条记录显示 **73 项**：58 项字段/向量分量，加 15 个标志位开关。原始标志值及其开关同时显示，便于整体输入或单个位调整。

| 参数组 | 项数 | 内容 |
|---|---:|---|
| 标识与显示 | 5 | 射弹 ID、三个名称文本 ID、HUD 图标哈希 |
| 弹道 | 10 | 口径、弹数、速度、质量、阻力、重力、模拟步数、寿命、寿命随机量、穿透速度衰减 |
| 伤害引用 | 1 | damage_info_type / damage_id |
| 资源与特效 | 8 | 推进/低弹药推进/尾迹/消散/解体/命中方向特效哈希、推进特效长度、射弹实体哈希 |
| 爆炸触发 | 7 | 触发角、命中后允许到期、命中爆炸 ID、近炸距离、延迟、到期爆炸 ID、解保险距离 |
| 命中与贴花 | 3 | 贴花尺寸、表面命中效果类型、跳弹命中效果类型 |
| 跳弹 | 6 | 最大次数、阈值角度/速度、角度损失、垂直/水平散布 |
| 音效 | 4 | 音爆、跳弹、尾迹开始/停止事件 ID |
| 效果模板 | 3 | 状态区域模板、命中特效伤害类型、火焰模板 |
| 射弹标志 1 | 14 | uint16 原始值和 bit 0–12 的 13 个开关 |
| 碰撞 | 2 | 射线检测模板、近炸碰撞过滤器 |
| 射弹标志 2 | 3 | uint8 原始值和 bit 0–1 的两个开关 |
| 附着偏移 | 3 | projectile_attachment_local_offset 的 X/Y/Z |
| 未知字段 | 4 | +0xA4 / +0xDC 浮点数、+0xE0 整数、+0xE4 标志位 |

每项均有英文、简体、繁体名称；提示保留原 JSON 字段名、偏移与存储类型。未确认含义的字段仍按参考文件的偏移命名。JSON 的 `index` 是导出顺序，`type` 才是射弹 ID；`_metadata` 和两个 `*_detail` 容器不是额外游戏参数。

原页将 `lifetime` 读到了 **+56**，实际 **life_time 为 +52，life_time_randomness 为 +56**，现已分别读取和编辑。旧 `lifetime` 配置键保留，绑定到正确的寿命位置。质量字段使用原始值，不添加未经确认的单位。

## 引用与兼容

本页只展示当前射弹自身的数据；伤害与命中/到期爆炸显示为可编辑的引用 ID，双击跳转到对应记录。0 为无引用；输入的非零目标必须存在于当前已加载数据中。

`status_effect_volume_template` 是状态区域模板枚举，`effect_damage_type` 是命中特效枚举，二者均不伪装成 `status_effect_id` 或 `damage_id`。射弹自身 ID 是只读记录标识。

保留 `calibre`、`pellets`、`velocity`、`mass`、`drag`、`gravity`、`lifetime`、`pen_slowdown`、`impact_explosion`、`expiry_explosion`、`fuse_proximity`、`fuse_delay`、`arming`、`blast_angle` 等旧配置键。原内联伤害参数的配置绑定仍保留，但不再在射弹页展开；重置当前射弹不会重置引用的伤害记录。

8 个 uint64 资源哈希使用完整十进制输入与显示，以两个精确 uint32 分量存储，不经过浮点数近似。打包校验修正只使用当前结构中确认为 float32 的字段，不把资源哈希或整数 ID 当作浮点数调整。

两组标志位开关与原始值共用同一字段，配置和预设只保存原始标志值；修改单个位时保留其余位，包括未命名的位。当前射弹数组解析允许记录数组后的校验修正尾部，不将尾部视为新增记录。
