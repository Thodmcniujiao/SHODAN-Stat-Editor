# ID 类型标注与双击跳转

引用其他记录的数值旁会显示类型，例如 `[projectile_id]`。
类型表达的是“这个数字引用什么”，不是它的二进制存储类型；普通伤害量、弹数等整数没有这种标记。

| 引用类型 | 双击后的目标 |
|---|---|
| projectile_id | 游戏数据 → 射弹id修改 → 对应射弹编号 |
| explosion_id | 游戏数据 → 爆炸id修改 → 对应爆炸编号 |
| damage_id | 游戏数据 → 伤害id修改 → 对应伤害编号 |
| status_effect_id | 游戏数据 → 状态效果id → 对应状态效果编号 |
| arc_id | 游戏数据 → 电弧id修改 → 对应电弧编号 |
| beam_id | 游戏数据 → 激光id修改 → 对应激光编号 |
| stratagem_id | 对应战备的编辑页 |

轰炸组件的 8 个 `ProjectileID` 槽都标为 `projectile_id`。
同样的跳转适用于武器射弹替换、爆炸破片的射弹、命中/到期爆炸、状态效果槽、
武器的电弧/激光记录，以及额外战备等已有引用字段。

- **单击数值**：可编辑字段保持原来的直接输入行为。
- **双击数值或该行标签**：读取当前 ID，打开目标类型的对应记录，并清除会遮住目标的搜索条件。
- **0、无效或尚未加载的目标**：保留当前页面并显示原因。
- **只读引用**：用于显示记录关系，不提供增减按钮；双击或按 Enter 可以跳转。
- **普通数值**：没有引用标记，双击不会把伤害量、弹数等误认成 ID。

跳转可以连续进行，例如 **轰炸射弹 → 命中爆炸 → 伤害 → 状态效果**。
跳转本身不会改变数值或写入游戏。页面上的同一伤害记录仍使用同一个数据字段，修改和重置会同步反映。

完整 ProjectileType 页的伤害、命中爆炸和到期爆炸 ID 可直接编辑并双击跳转；射弹自身 ID 为只读标识。模板/特效枚举不会被误标为伤害或状态记录引用。

完整 ExplosionType 页的伤害、破片射弹及电弧 ID 同样可直接编辑并双击跳转；爆炸自身 ID 为只读标识。

完整 ArcType 页的伤害 ID 同样可编辑并双击跳转，电弧自身 ID 为只读标识；“爆炸特效资源哈希”不标成爆炸 ID。

完整 BeamType 页的伤害和爆炸 ID 可编辑并双击跳转，激光自身 ID 为只读标识；DangerLevel 和命中特效类型保留为枚举。

伤害、电弧、激光的目标页已接入真实记录，不再是占位页。
伤害、电弧、激光记录均展示完整的自身组件，通过引用 ID 访问相关记录。
新增记录页可以使用原有的保存配置、预设、重置和写入流程。

维护：引用由 `MOD.references` 的语义类型和行元数据统一处理，
不要根据中文/英文标签或“是否为整数”猜测引用类型。
新增可编辑引用行应填写 `reference_type`；只读关系通过 `MOD.references.row` 创建，
不进入可写配置或预设字段。

验证：`tests/test_reference_navigation.lua` 使用隔离的真实游戏数据，
检查 8 个射弹槽、六类数据引用、连续跳转、单击输入、双击配对、无效输入保留、
缺失目标、记录间共享数值、配置/预设，以及 GDI 界面绘制；测试不写入游戏文件。
