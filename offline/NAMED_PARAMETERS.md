# 其他已解析字段

入口：**杂项与预载 → 其他已解析字段**（列表最后一项）。沿用编辑器原有列表、搜索、数值输入、单项/整页重置、五组预设、配置保存和写入游戏功能。

## 角色名称字段

从安装游戏的 `generated_entities.dl_bin` 读取 `CharacterNameComponentData`，类型 `0x7655097B`，当前 91 条实体记录，每条 16 字节、4 项字段。字段在类型库核对通过后开放：

| 记录内偏移 | 字段 | 类型 |
| --- | --- | --- |
| +0 | race | RaceType / u32 |
| +4 | random_name_template | 本地化文本 ID / u32 |
| +8 | character_name | 角色字幕名称 ID / u32 |
| +12 | use_persistent_seed | 单字节布尔 |

默认提供绝地潜兵实体的可读名称，其他实体沿用已有武器/敌人名称或资源路径。可以通过实体十六进制哈希搜索。主绝地潜兵为 `4D1C334D294DFA97`。

作用范围是角色字幕名称和随机名字模板；该页没有存放自定义联网昵称的字符串输入框。整数文本 ID 按 u32 保存，布尔按单字节保存。实体文件构建时，这一组件的整数位模式不会被用作浮点校验修正值。

## 字体样式字段

从 `generated_font_settings.dl_bin` 读取 `FontSettings` 的全部设置块。当前有 6 组语言字体配置，每组含 13 个 HUD 样式和 17 个菜单样式，共 180 个样式、720 项可编辑字段：

| 样式元素内偏移 | 字段 | 类型 |
| --- | --- | --- |
| +0 | style | 样式枚举 / u32 |
| +4 | settings.type | FontType / u32 |
| +8 | settings.font_size | f32 |
| +12 | settings.shadow_range | f32 |

顶部只读显示字体集的 `name` 资源哈希、`languages` 和 `resource_package`。按当前界面语言优先排列对应字体集；简体中文通常为 `cn`，繁体为 `tc`。这是共用本机样式，影响所有使用该样式的界面元素。数组长度、指针和资源集标识不作为可编辑数值。

记录大小、嵌套类型、成员大小/类型、动态数组偏移与边界均检查通过后才创建编辑行。样式名称参考已有枚举资料；值本身来自安装游戏，不是把研究报告中的旧快照数值写进界面。

字体文件的校验修正仅把真正的字号/阴影 f32 字段列作浮点候选，不将样式枚举或资源哈希位模式当成浮点数。写入仍经过现有的构建、加密和回读校验流程。

## 网络接口参考

只读列出已核查的 `rpc_ingame_chat_message`、`rpc_set_player_info`、`rpc_sync_player_info` 操作名、名称哈希和参数数量，注明 2026-10-28 资源快照。尚未确认参数成员名的索引不作为可编辑字段。这些操作描述不等于网络昵称内容，因此该页不提供写入功能。
