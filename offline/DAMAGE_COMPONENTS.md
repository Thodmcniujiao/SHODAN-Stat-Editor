# DamageType 伤害组件

界面中的组件名为 **DamageType / 伤害类型**，对应游戏 `generated_damage_settings.dl_bin` 中的 `DamageSettings → DamageInfo`。当前类型库确认记录为 **76 字节、19 个标量参数**，没有额外未显示字段。

组件标题高于下方两个参数组；“伤害”“状态效果”保持原来的参数组样式。

## 参数与字节位置

| 参数组 | 参考字段名 | 中文名称 | 偏移 | 类型 |
|---|---|---|---|---|
| 伤害 | DamageTypeID | 伤害 ID | +0 | 只读记录 ID；可双击跳转 |
| 伤害 | Damage | 伤害 | +4 | int32 |
| 伤害 | ArmorDamage | 耐久伤害 | +8 | int32 |
| 伤害 | PenetrationAngle25 | 穿甲等级（正面命中，25°） | +12 | uint32 |
| 伤害 | PenetrationAngle60 | 穿甲等级（小角度，60°） | +16 | uint32 |
| 伤害 | PenetrationAngle80 | 穿甲等级（大角度，80°） | +20 | uint32 |
| 伤害 | PenetrationAngle90 | 穿甲等级（极端角度，90°） | +24 | uint32 |
| 伤害 | Demolition | 破坏力 | +28 | uint32 |
| 伤害 | ForceStrength | 硬直力 | +32 | uint32 |
| 伤害 | ForceImpulse | 击退力 | +36 | uint32 |
| 伤害 | ElementType | 元素类型 | +40 | uint32 枚举 |
| 状态效果 | StatusEffectType1–4 | 状态效果 1–4 ID | +44、52、60、68 | status_effect_id |
| 状态效果 | StatusEffectFactor1–4 | 状态效果 1–4：每次命中强度 | +48、56、64、72 | float32 |

元素类型同时显示数值及中英文名称：0 无 / None，1 火焰 / Fire，2 电击 / Electricity，3 酸液 / Acid，4 流血 / Bleed，5 毒气 / Gas。

所有参数有英文、简体及繁体名称，提示保留参考字段名、类型与偏移。状态 ID 支持当前游戏实际加载的全部状态记录；单击输入、双击跳转至对应状态记录，仍要求从第一个槽依次填写、从末尾依次清空。空强度的新状态获得原有建议强度，未在建议表内的状态使用 1。

## 接入范围和兼容

非敌人页面统一使用完整视图，包括主副武器、支援/架设武器、炮台和载具武器、投掷物及其电弧/破片、爆炸、背包/地雷、轨道/飞鹰武器、热量阶段及其自身伤害、状态持续伤害，以及游戏数据的伤害/射弹/爆炸/电弧/激光/状态记录。原本只展示部分字段的位置同样补齐 19 项。

原有持续伤害和状态持续时间继续保留；其伤害记录也使用完整 DamageType 视图。多个来源引用同一伤害记录时继续共享同一个字段对象。

射弹 ID 页后续已整体替换为 ProjectileType，只显示射弹自身字段和伤害引用，通过双击跳转进入伤害记录；不再在射弹页内展开 DamageType。详见 `PROJECTILE_COMPONENTS.md`。

爆炸 ID 页同样已整体替换为 ExplosionType，仅保留爆炸自身字段及引用，详见 `EXPLOSION_COMPONENTS.md`。

电弧 ID 页已整体替换为 ArcType，伤害 ID 通过双击跳转，详见 `ARC_COMPONENTS.md`。

激光 ID 页已整体替换为 BeamType，伤害及爆炸 ID 通过双击跳转，详见 `BEAM_COMPONENTS.md`。

“游戏数据 → 伤害 ID 修改”只显示当前记录自身的 19 个参数，不展开所引用状态的伤害组件或持续时间。双击状态效果 ID 跳转到对应状态记录，再双击其伤害 ID 可继续跳转。旧版在当前页保存的关联状态参数绑定保留于隐藏行，以兼容已有配置及预设。

**敌人设置使用原来的行、参数组、范围和控件，不套用新视图。** 未通过当前类型库布局检查时，新视图不启用，保留原有解析。

保留旧 `damage`、`durable`、`ap_*`、`demolition`、`stagger`、`push`、`slotN`、`slotN_strength` 及各种来源前缀。旧 `status<ID>_strength` 别名继续指向对应槽强度；热量阶段自身伤害的旧聚合配置和预设键也继续有效。记录 ID 为只读引用，不写入配置和预设。

另与 build 20261028-012101 比对：249 个敌人设置页面完全相同，全部 37,504 个旧配置/预设字段保持原数据绑定。所有验证均不安装或写入游戏文件。
