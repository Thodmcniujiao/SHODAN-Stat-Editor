# 当前装备栏：本地存档编辑

入口：**军械库 → 当前装备栏编辑**。

- **存档配装**：头盔、护甲、披风、主武器、副武器、手雷，以及胜利姿势 ID、玩家卡片背景 ID。
- **装备 ID 目录**：从本机当前版本的 `LoadoutEntryComponentData` 和 `HelldiverCustomizationKit` 读取物品定义。输入装备槽类别和搜索词，再点“选用”。目录不是账号解锁清单。
- **存档与备份**：选择自动发现的 Steam 存档，或输入完整文件路径；可指定和恢复备份。
- **未命名存档字段**：外观记录附近 8 个 u32 原始字段，可修改，但没有把它们猜测标成称号、体型或语音。

值支持十进制、`0x` 十六进制。已确认的六个装备槽也支持唯一匹配的物品名称，并验证当前版本的物品类别。当前名称显示在右侧，ID 和解压偏移在提示中；点击值进入 ID 输入。

修改暂存在编辑器中。此页底部“写入存档”和页内同名操作只写所选存档；其他页面的“写入游戏”继续处理游戏资源文件。写入前必须关闭游戏。每次写入先备份当时的原文件，校验临时输出，再替换目标；若磁盘存档已由其他程序更新，则要求重新读取，避免覆盖新进度。恢复也会备份恢复前的文件。Steam Cloud 仍可能同步或覆盖本地存档。

配装预设通过底部“预设 → 存档配装”管理，以名称保存于 `preset_library.json`。旧 `player_save_presets.json` 会自动导入并保留原文件。载入预设只是暂存修改，需返回配装页点击“写入存档”。

## 已核对的结构

源路径：`<Steam>/userdata/<account>/553850/remote/testament_new.sav`。支持本轮确认的容器签名、版本和解压数据版本 `0x107`；其他版本不猜测写入。

| 字段 | 完整解压流偏移 | 证据 |
|---|---:|---|
| 主武器 | `0x11` | 当前物品 ID 和类别匹配，旧 CT 军械库相对偏移 `0` |
| 副武器 | `0x15` | 当前物品 ID 和类别匹配，相对偏移 `4` |
| 手雷 | `0x19` | 当前物品 ID 和类别匹配，相对偏移 `8` |
| 头盔 | `0x121` | 当前 kit ID 和类别匹配，相对偏移 `0x110` |
| 披风 | `0x125` | 当前 kit ID 和类别匹配，相对偏移 `0x114` |
| 护甲 | `0x129` | 当前 kit ID 和类别匹配，相对偏移 `0x118` |
| 胜利姿势 ID | `0x135` | 旧 CT 军械库相对偏移 `0x124`；未完成当前动作目录解析 |
| 玩家卡片背景 ID | `0x139` | 旧 CT 相对偏移 `0x128`；未完成当前背景目录解析 |

未命名字段偏移：`0x11D / 0x12D / 0x131 / 0x13D / 0x141 / 0x145 / 0x149 / 0x14D`。编辑仅替换对应的四字节整数，不推断字段用途。

容器 `+0x0C` 为标准 CRC32，覆盖文件 `[0x10, EOF)`；`+0x10` 是文件总长减 28。`+0x14` 和 `+0x1C` 为解压长度，`+0x24` 起依次为压缩长度和 raw LZ4 数据。块解压长度为 65,536，末块零填充在声明长度之外。写回只重新压缩变化的块，其他压缩块逐字节保留；内部未知标记、填充及非目标字段也保留。

不把解压流偏移当成压缩 `.sav` 的磁盘偏移，不写游戏 DLL，不修改 Steam 云端接口或账号所有权。

## 验证范围

测试使用真实存档只读输入和隔离的写入目标，覆盖 CRC32/LZ4、无修改输出逐字节一致、原生 LZ4 独立解码、非目标字段/块保持、u32/类别验证、游戏运行/外部文件变化/写入失败/替换失败处理、备份恢复、跨模型读取预设，以及实际编辑器导航、输入、预设和中英文 GDI 渲染。

本次没有把测试修改写入用户实际存档，也没有启动游戏确认配装是否被接受；运行时加载和服务器校验仍需游戏实测。解析与本地写回成功不会授予账号未拥有的物品。
