# 启动性能与按需加载

2026-10-30 优化。

## 加载方式

- 武器页先显示匹配组件标题，展开时才建立该组件的完整参数行。按旧保存 ID 查询时也会自动建立相应行，因此不需要先手动打开组件才能恢复配置或预设。
- 通用组件视图按需建立参数行；没有该组件的灰色实体占位在首次进入对应类别时建立。完整实体目录、搜索、十进制／十六进制跳转与“显示无本组件实体”保留。
- 共享字段的星号通过组件记录范围和实际改动索引判断，不为显示星号而提前加载所有组件。修改、重置、预设和重新扫描仍共用原字段及保存 ID。
- 初始化按批次执行，批次间返回窗口消息循环；正常编辑时批次检查不会触发协程切换。
- 实体目录导出索引使用内容指纹。名称、分类、组件归属或目录内容改变时重新生成，普通启动且内容一致时跳过重写。手动“重载JSON”会强制更新导出索引。

索引指纹只缓存文档型目录导出，不缓存或复用游戏参数偏移。游戏文件版本检查、解密校验、当前类型库布局校验和原生哈希检查保留。

## 实测范围

对同一台机器、同一份游戏数据和配置，用隔离发布包与原生 GDI 离屏画布测量 Lua 入口到首个可编辑画面的时间。资源索引缓存已建立；未清空 Windows 磁盘缓存，也不含 Windows 创建进程与加载 DLL 的时间。

优化前两次基准为 6.150 秒和 5.954 秒，平均约 6.05 秒。优化后的稳定复测及具体发布 build 结果见本次任务的性能记录。优化初测约 3.4 秒；启动字段对象从 416291 个降为 112642 个，实体目录页面占位从 51975 个降为 3465 个。完整参数仍可在首次使用时加载，首次展开复杂组件会有相应计算成本。
