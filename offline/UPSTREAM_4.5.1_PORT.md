# 上游 4.5.1 移植记录

对照 `UPSTREAM_4.5.1_REVIEW.md` 的 🟡/❌ 项，移植上游 4.5.1 中“字段已有、只差一行”的策展行，并补齐缺少的组件、参数与名称。
上游代码按差异块逐块合入（只取新增，保留本地已有功能）。四种语言的词条从上游 `MOD.langs` 补入（简体 / 繁體 / Русский），
本地新增的说明自行翻译。

## 与上游的取舍：自由度优先

上游面向新手，选项行只允许几个“安全”值；本 fork 以最大修改自由度为原则，移植时做了这些改动：

- **不在共享字段上加白名单**：上游给阵营（1/2/4/8）、收枪节点（背/胯）、军械库栏位（1/3）的字段加了 `allowed`，而这些字段
  也被组件页使用，会连带锁死组件页。这里全部去掉，组件页与策展行都能写任意值。
- **选项行保留，但可直接输入任意值**：方向键仍在常用值之间切换；直接输入时阵营 0-255（按位相加，可多阵营）、栏位 0-255、
  拾取交互类型 0-255、投弹模式 0-255，越出已知值时标签显示数字。
- **组合写入的选项行旁边列出原始字段**：收枪位置（节点哈希 + 3 个旋转 + 3 个偏移，共 7 行）、单侧挂架复制（投放数量）。
  原始行与选项行共用同一个字段，只保存一份数值，不会互相覆盖。
- **范围放宽**：锁定距离 0-100000、哨戒炮瞄准 ±360°、机瞄缩放 0-1000、每次投放 0-8（挂架槽位数）。
- **显示条件只做布局校验**：无限弹药、过载爆炸对开/关两种默认值都显示（可以关掉原本开着的）。
- **近战打击显示整条伤害记录**：人物数据和刺刀枪上的近战不再只有 5 项，而是 DamageInfo 的全部参数（伤害、耐久、各角度穿甲、
  拆毁、硬直/击退、元素、状态效果），与伤害类型组件页相同。
- 索引类字段（如音频索引）不做策展行，只在组件页按原值可改。

- 版本号 4.1.0 → **4.5.1**（窗口标题同步），格式不变；构建时间仍在标题的 `build <时间>`。
- 搜索 `*`：只列出改过的条目（跨所有页面，名称与描述的改动也算），可与关键词同用；搜索框旁加 **\*** 按钮，Esc 清关键词时保留该开关。
- “自上次写入以来的改动”只在字节或编辑器自有值真的变化时计数（载入预设、关闭未改动的输入框不再误报）。

## 归档读取层（第三步，脱离 Filediver）

- `offline/archives.lua`：读 `bundles.nxa`（DSAA 列表）与 `bundles.NN.nxa`（DSAR 分块，LZ4），也读完整版的独立归档；按名称/偏移读取、文件目录、按资源取 main/gpu/stream，按类型建索引（`SAX1` 缓存，按游戏版本区分）。
- 预载（`preload_io.lua`）与实体拆毁的 Unit 克隆（`unit_aliases.lua prepare_native`）改为原生读取；Filediver 仅在原生读取失败且已配置时兜底。
- 测试：`tests/test_archives.lua`（合成的独立归档与 bundle，LZ4、目录、资源、索引及其缓存）。

## 名称与描述（第三步，方案 B）

- 游戏英文文本在启动时读出（`offline/game_texts.lua`，265 个 strings 文件，只全读英文；索引缓存 `strings-index.bin`）。
- 参数表下方两个输入框：名称 / 描述（按条目的游戏文本 id）；配置行 `rename <hash> name|desc <文本>`，参与“只看改动”和重置。
- 长度：名称建议 ≤60、描述 ≤400，超出只在底部提示，仍会写入（硬上限 1000 / 4000）。
- 写入：每种语言中含该 id 的 strings 文件都改写，放进本编辑器自己的 `<归档>.patch_N`（与预载补丁合并，`game_texts.merge`）；游戏原归档不动，“恢复游戏原始文件”删除补丁。

## 载具操控、机甲移动、敌人动画速度（第四步）

数据来自游戏数据包（`offline/physics.lua`）：按索引在**任意含该文件的归档**中查找（上游用固定归档名表），只在第一次打开载具/敌人页时读入需要的文件（约 74 个、3 MB；游戏共有约 4800 个物理文件、145 MB），面板像表一样直接编辑内存，写入时只把变化的文件放进基础归档 `9ba626afa44a3aa3` 的本编辑器补丁（与名称/描述同一个补丁）。

- **载具操控**（物理文件 `5F7203C8F280DAB8`，按载具实体命名；所有带载具组件的实体都尝试）：
  - 操控：重量、重心高度 / 前后 / 左右（本 fork 新增前后、左右）、引擎扭矩、最高转速、各挡传动比、两组刹车（按车轮归属标为前/后，手刹说明）。
  - 车轮：抓地、半径、弹簧刚度、阻尼、悬挂行程；4 轮车分前/后，坦克的负重轮合为一组。
  - 定位：质量块按 `FF×28 + 44 00 00 00` 标记倒推，`VR  ` 块按 8 个偏移找 `VRW/VRE/VRT/VRB`，每块校验标签，找不到就不显示；战备实体页按各自实体名读取物理文件，双实体载具也分别编辑，不把另一实体的物理参数并入主体。
- **机甲移动**（四台外骨骼共用状态机 `79E4B3D2DA5E45E3.A486D4045106165C`）：行走（除数，反向倍率）、转身、跺脚、上下机、落地、硬直恢复；本 fork 另加“其他动画速度”（其余常量播放速度的状态）。
- **敌人动画速度**（各敌人单位的状态机）：攻击 / 受击硬直 / 其余三行倍率，同一状态机的敌人共享并注明共用对象；阵营全局倍率新增“动画速度 (x)”。实体→状态机对照沿用上游表（`offline/enemy_anim.lua`，162 个实体、68 个状态机），没有对照时尝试与敌人同名的状态机；状态数与分类表不符时全部按“其余”处理。
- 核对：2026-10-30 游戏文件中 5 台车的数值与上游注释一致（例：Gunner FRV 3000 kg、重心 -0.375、5000 rpm、750 扭矩、4 挡；坦克 30000 kg、10 轮），68 个敌人状态机的常量状态数与分类表全部吻合；游戏内效果沿用上游 2026-10-28 的实测。
- 范围（自由度优先）：重量/扭矩/刹车 0–1 亿、转速 0–1000 万、传动比 ±1000、抓地 0–1000、半径 0–100 m、弹簧/阻尼 0–100 万、行程 0–10000、重心 ±100 m；机甲与动画倍率 0–100（行走 0.01 起）。
- 测试：`tests/test_physics.lua`（只读一次、对齐、只补变化的文件、与名称/描述合并进同一补丁、复用本编辑器已有补丁）。
