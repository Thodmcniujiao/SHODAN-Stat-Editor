# 命名预设与独立编辑模式

底部操作栏统一为：**写入游戏／恢复游戏原始文件／预设／设置**。存档配装页前两个按钮按原有存档流程显示“写入存档／恢复存档备份”。页面内的 1–5 快捷槽、保存/读取/清除按钮及 Ctrl+数字快捷键已移除。

点击“预设”进入独立模式：原来的顶部主导航、页面分类、实体列表和参数表全部隐藏。左侧选择命名预设，右侧可载入、用当前修改覆盖、重命名或删除；左下角“保存为新预设”创建条目。使用金色工作区边框外的“返回编辑”、Esc 或再次点击底部“预设”返回，恢复之前的页面、选中项、滚动和搜索结果。

“设置”也作为独立工作区显示，底部同名按钮或“返回编辑”退出。切换工作区前会先提交正在输入的参数；无效输入会阻止切换，避免丢失编辑内容。

## 描述、文件夹分组与参数明细

- 每个预设可直接双击描述框添加用途、说明和注意事项。支持中文、多行及 `#`；Enter 保存，Shift+Enter 换行，Esc 取消。描述随预设文件一起分享，覆盖参数时保留。
- 左侧顶部用 `< / 分组名称 / >` 切换分组，点击名称打开列表；“全部分组”显示所有预设，“未分组”对应 `Presets` 根目录。
- 分组直接对应 `Presets` 下的子文件夹，支持中文和多级目录。可以点击“新建分组”，或在右侧“分组”按钮中移动选中的预设。当前分组内新建的预设会直接保存到该文件夹。
- 在资源管理器中整理文件夹后，重新打开编辑器即可识别；`backup` 目录保留给旧格式备份，不作为预设分组。编辑器运行期间文件被外部修改或移动，会阻止覆盖并提示重新打开。
- 右侧“已保存内容”以折叠列表显示修改器的全部主页，默认全部收起；主页展开后只列出有改动的子页，子页再展开显示具体改动参数。可同时展开多个主页、子页，没有修改的子页和参数不显示。改动所在页面显示 `*` 及数量，参数逐项列出对象、名称、字段 ID 和“原始值 → 预设值”，改动值显示金色星号。切换预设后重新收起全部页面。
- 左侧预设旁的数字是与原始值相比的改动总数，与右侧各主页的星号数量合计一致；右下角另外显示完整快照的记录数。快照会保留未改动的配装字段、默认预载设置等内容，它们不算参数改动。
- 明细预览直接读取预设文件中的值，无需载入；不会改变当前编辑内容。无法在当前版本解析的字段仍显示原哈希和字段 ID。
- 存档配装会保存捕获时的原始字段用于星号判断；旧预设若没有这份基线，则使用当前已读取存档的原始值。没有可用基线时显示预设值和星号。
- 鼠标放在左侧列表、右侧参数区或描述区域时，滚轮分别滚动对应内容；下拉菜单也支持滚轮。右下方按钮可翻阅较长的参数列表。

## 全局预设

原来的“游戏参数／敌人参数／存档配装／预载方案”四个分类已合并为一个列表“全局预设”。每个预设一次保存当前的全部修改：

- **游戏参数：** 所有页面的参数修改（武器、战备、实体组件、星球与任务、游戏数据等），以及护甲被动的叠加和开关。
- **敌人参数：** 敌人编辑、敌人生成、敌人数据（全局倍率）、AI设置、刷怪编辑器中的修改。
- **拆毁修改：** 实体拆毁的阈值覆盖。
- **存档配装：** 当前打开存档中已编辑的配装字段。
- **预载方案：** 包清单、额外包选择、加载目标、数组修改。

载入会替换全部已暂存的修改。写入游戏文件仍需点击“写入游戏”，写入存档仍需点击“写入存档”。

旧的分类预设导入后标为“部分方案”：载入时只合并它记录的那一类，不清除其他修改。对它点击“用当前修改覆盖”，即可升级为完整的全局预设。

覆盖和删除保留原有二次点击确认。快捷键：
- Enter：载入
- Insert：新建
- Shift+Insert：覆盖
- F2：重命名
- Del：删除
- Esc：返回

预设列表支持滚轮、上下键和翻页按钮。

## 存储与旧数据

预设保存在 **exe 旁边的 `Presets` 文件夹**，每个预设一个文件，以预设名命名：
- 例如 `Horde.json`、`精英.json`。名字里 Windows 不允许的字符换成 `_`；同名的预设依次是 `精英.json`、`精英 (2).json`。
- 文件里有格式标记、编号、名称、文字描述和全部修改。改名会改文件名，删除会删掉文件。
- `preset_index.json` 记录下一个编号和已导入的旧预设（删除过的导入不会再回来），请勿删除。
- 文件夹里还有一份说明 `README.txt`；预设页右上角的“打开预设文件夹”可以直接打开它。
- **分享：** 把某个预设文件复制到别人的 `Presets` 文件夹，重新打开编辑器即可出现；编号冲突会自动换一个新编号。
- **备份：** 复制整个文件夹。不是预设格式的 `.json` 文件会被忽略，也不会被改写。
- 发布包里已经带有这个文件夹（只有说明文件，没有预设）。
- 早期的全局预设版本把所有预设放在一个 `preset_library.json` 里。新版本启动时会把它拆成单独的文件，原文件移到 `Presets\backup\` 保留。

每个程序文件夹有自己的 `Data` 与 `Presets`，不再跟随 `presets_folder.txt` 自动导入其他程序或用户目录。更新到新文件夹时，请手动复制这两个目录；名称配置也应随 `Names` 一起保留。旧版 AppData 的完整迁移步骤见 [便携数据指南](PORTABLE_DATA.md)。

预设库条目使用稳定 ID，不再限制每个对象五个快捷槽。新库采用经过结构验证的 JSON：先写临时文件，读回验证后再原子替换；如果另一个编辑器改过库文件，则拒绝覆盖。

首次使用只从本程序的 `Data` 自动导入旧格式（包括手动放入 `Data/preset_library.json` 的命名预设）：

- `preset_01.txt` 至 `preset_50.txt` 和 `enemy_preset_01.txt` 至 `enemy_preset_50.txt`。
- `weapon_presets.txt` 中的旧快捷槽，转换成“旧单项预设”命名条目；这类条目只合并自己记录的参数，不清除其他修改。
- `player_save_presets.json` 的旧配装预设。
- `preload_config.json` 内的旧预载预设。

原文件保留。导入来源有独立标记，重启不会重复导入；删除已导入条目后，也不会从旧文件自动恢复该条目。新建、改名、覆盖和删除只更新新库。

实现分为 `preset_library.lua`（存储、校验、迁移）、`preset_files.lua`（Windows Unicode 文件名读写）、`preset_controller.lua`（类别和操作）、`preset_details.lua`（按修改器分页生成只读参数明细）、`preset_panel.lua`（独立界面）、`editor_footer.lua`（底部布局）。测试使用隔离配置目录与离屏 GDI，未自动写入真实游戏资源或存档。
